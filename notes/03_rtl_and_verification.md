# Step 3 — RTL and verification log

## Decisions made with you (2026-10-27)

- Array **4 × 10** (option B), **2x2 tiles**, **50 MHz** sign-off clock.
- Accumulator: **24-bit internal, saturating**, exact for K ≤ 65,535 (|acc| ≤ 128·K). Readout is
  `sat16(acc >>> shift)` with a 5-bit shift and floor semantics, the same contract as the FPGA's `sat16_shift`.
  One shared shifter on the readout path instead of one per row.
- Area cost vs 16-bit (local Yosys, tt corner, full design): **38,623 µm² vs 34,548 µm² (+4,075, +11.8 %)**
  with identical readout logic. The plain 16-bit design without the shifter (Step 2) was 33,028. The
  LibreLane numbers from the real hardening are in `04_signoff.md`.

## Bugs found, and what each one taught

1. **SPI rate (spec bug).** MISO moves ~3 clk after an SCK fall, and the TT mux adds up to ~20 ns. At
   f_clk/8 the master would sample it as it changes. Spec is now **f_SCK ≤ f_clk/16**.
2. **Testbench: cocotb deferred writes.** Two read-modify-writes of `ui_in` in one timestep both read the
   stale value. The second undid the first, so SCK stuck high and every byte read 0xFF. Fix: a Python shadow
   register. This is a testbench bug, not RTL, but it made 9/9 tests fail, so the RTL was never trusted until
   it was explained.
3. **Shared loop variables (synthesis-only bug).** `integer i`/`r` reused across `always` blocks simulates
   fine and is accepted by Vivado. Yosys treats it as one variable with multiple drivers, and LibreLane
   stopped with "34 Yosys check errors". Fix: one loop variable per block. Local synthesis now runs
   `check -assert`, so this class of error fails on the PC, not in CI.
4. **CLEAR did not clear ILLEGAL** (doc/RTL mismatch), found while writing the model.
5. **Gate-level sampling (practice design).** Sampling at `ReadOnly()` right after the edge passes RTL and fails
   GL (unit-delay cells). All TMAC tests drive and sample on falling edges.

## Results

- RTL: **9/9 pass** (`test_internal_saturation` alone is ~6,600 SPI transactions, ~1 min).
- Mutation: 6 injected bugs, **6 caught**, each by the test designed for it.
- Local synthesis: `check -assert` clean, 0 problems.
- Gate level: see `04_signoff.md`.
